## Título del proyecto

Pixelshift

## Autor del proyecto

Alejandro Martin Herrera

## Introducción del proyecto

Este proyecto será principalmente una herramienta de compresión de imágenes y videos, con la posibilidad de implementar conversiones de imágenes y videos en el futuro. También servirá como un host para guardar estos archivos de forma pública o privada.

## Finalidad

La finalidad de este proyecto es crear un sitio centralizado donde los usuarios puedan comprimir imágenes y videos, guardarlos y compartirlos con amigos. El propósito de este proyecto es ofrecer una única plataforma para comprimir, convertir y almacenar imágenes y videos, ya que existen muchos sitios que realizan estas funciones, pero están llenos de publicidad y son difíciles de navegar.

## Objetivos

-   Crear un sistema de registro y login.
-   Comprimir imágenes y videos, y guardarlos en el servidor.
-   Permitir a los usuarios compartir enlaces de imagenes/videos.
-   Crear un diseño elegante y hacer énfasis en la facilidad de uso.

## Medios hardware y software a utilizar

### Hardware

Se utilizará un ordenador con los siguientes componentes:

-   Placa base: MSI X570 Gaming Edge WiFi
-   Procesador: Ryzen 7 5800X
-   RAM: Corsair Vengeance DDR4 32GB 2600MHz
-   GPU: EVGA 3070Ti
-   PSU: Corsair RM850x

### Software

Se utilizará principalmente _VSCode_ con las extensiones necesarias para el desarrollo de este proyecto. Además, se utilizará lo siguiente:

-   Django para el backend.
-   React para el frontend.
-   Tailwind para los estilos.
-   AWS EC2 para el despliegue del backend.
-   AWS S3 para el despliegue del frontend.

Esta separación de despliegues será ideal para la escalabilidad del proyecto.
